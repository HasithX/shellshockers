# Shell Shockers Aimbot & ESP (LM v2.5)

A userscript for [Shell Shockers](https://shellshock.io/) supporting Violentmonkey and Tampermonkey.

## Features
- **Auto-Fire:** Trigger-based firing with FOV cone gating, delay pacing, and watchdog protection.
- **Aimbot:** Camera orientation with smooth tracking and customizable FOV.
- **ESP & Tracers:** Enemy bounding boxes, line tracers, name & distance labels, and health indicators.
- **Ammo & Health:** Live magazine/reserve ammo readout, infinite ammo toggle, and max health hold.
- **In-Game GUI:** Draggable configuration panel toggled with `Insert` or `~` (Backquote).

## Installation
1. Install [Violentmonkey](https://violentmonkey.github.io/) or [Tampermonkey](https://www.tampermonkey.net/) in your browser.
2. Create a new userscript and paste the contents of `lm.user.js`.
3. Save the script and load `https://shellshock.io/`.
